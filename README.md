# bakwigil-data

바퀴길 앱이 받아 가는 자전거 코스 데이터입니다. 지역 경계(`regions/`), 시도별 코스 목록(`index/`), 코스 경로(`courses/`), 검색어(`search.json`)가 있고, 앱은 `manifest.json`의 `version`과 파일 해시를 보고 바뀐 파일만 받아 갑니다.

## 코스에 대해 꼭 알아 두세요
- 코스는 OpenStreetMap에 그려진 길 위에서 **프로그램이 자동으로 만들었거나(자동 생성)**, 지도에 등록된 자전거 노선에서 잘라 낸 것입니다. **사람이 현장에서 직접 확인한 코스가 아닙니다(미확인).**
- 고속도로·자동차전용도로·자전거 금지 길, 출입금지·군사지역, 국립·도립·군립공원 구역, 계단·등산로, 자전거 사고다발지역 등을 지도 정보로 걸러 냈지만, 지도에 표시되지 않은 통제·공사·사유지·차단기는 알 수 없습니다. 임도는 산불 예방 기간 등에 통제될 수 있습니다.
- 출발 전에 현장 안내와 통제 여부를 확인하고, 문제가 있으면 앱의 "이 코스 문제 신고"로 알려 주세요.
- `주의` 표시 코스는 빈 지역을 채우려고 품질 기준(예: 시군구 안에서만 달리기)을 낮춘 코스이고, `도로 주행 주의`는 일반 차도 구간이 있는 코스입니다.
